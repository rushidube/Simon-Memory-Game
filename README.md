# Simon Memory Game

An interactive Simon Memory Game built using **HTML, CSS, and JavaScript**.  
The game challenges players to remember and repeat an increasing sequence of colored tiles.

## Features

- Dynamic level progression
- Random sequence generation
- Sound effects for each tile
- Interactive UI with color animations
- Start and restart controls
- High score tracking using browser **localStorage**

## Technologies Used

- HTML
- CSS
- JavaScript (DOM Manipulation)

## How to Play

1. Click **Start** to begin the game.
2. Watch the sequence of colors.
3. Repeat the sequence by clicking the tiles in the same order.
4. Each level adds a new step to the sequence.
5. A wrong click ends the game.
